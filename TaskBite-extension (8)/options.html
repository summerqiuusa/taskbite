Set up TaskBite

The help button needs an AI to explain the problem you select. Pick either option below. There are no canned tips: if neither is set up, help is off.

Option A: Free on-device AI (no key)

Uses the AI built into Chrome. It runs on your computer, costs nothing, and the part you select never leaves it. It needs a recent Chrome on Windows, Mac or Linux (or a Chromebook Plus), about 22 GB of free space for a one-time download, and a graphics card with 4 GB+ of memory or 16 GB of RAM. Many school Chromebooks can't run it.

Before you start

  • Your key is saved only in this browser, and it is only ever sent to the provider you picked.
  • When you use Get help, the screenshot of the part you select and the assignment's name and description are sent to the provider you picked. Nothing goes to any TaskBite server.
  • API use is billed by your provider, usually a small amount per question. Set a spending limit in their dashboard.
  • Most providers require an adult to create an API account. If you're a student, ask a parent or guardian to make the key with you.
  • TaskBite explains the concept, shows the method, and checks your work. It doesn't give final answers.
  • You can skip this and use the timer and checklist only; the help button just needs one of the two options above. Reopen this page with the ⚙ button in the popup.

Focus mode: sites that stay open

When you lock in, your assignment's site stays open, and so does anything the assignment sends you to (a Google Doc or Slides, another site, a login page). Sites you type in yourself are blocked. List any extra sites to always allow (one per line).
