TaskBite

A Chrome extension for students who struggle to start and finish homework, made specifically with students with ADHD in mind. It pulls assignments from school portals, estimates how long each one takes, orders based on importance, runs a focus timer, can block distracting sites, and has an "I need help" button that explains the problem you select without giving the answer.

Works with Canvas, Google Classroom, Moodle, Blackboard and Schoology, (however only tested with Canvas and Google Classroom so far)

How to install from Github:

1. Download the code

Open the GitHub repository page for TaskBite.
Click the green Code button.
Click Download ZIP.
Find the downloaded file (usually in your Downloads folder) and unzip it.
Windows: right-click the ZIP, then Extract All...
Mac: double-click the ZIP.
Open the unzipped folder and make sure you can see manifest.json directly inside it. If you only see another folder, open that folder. The folder that contains manifest.json is the one you will load.

Then open Chrome and go to this address:
   chrome://extensions
Turn on Developer mode (toggle in the top-right corner).
Click Load unpacked.
Select the folder that contains manifest.json and click Select Folder (Mac: Open).
TaskBite now appears in your extensions list.
